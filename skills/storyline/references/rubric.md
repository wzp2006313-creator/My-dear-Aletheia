# Storyline Rubric

7 个维度，每个维度 5 分，满分 35 分。先检查红线，再逐维度评分。

---

## 术语定义

- **关键论断**：会影响核心判断或建议走向的陈述。删掉它，结论就站不住。
- **利益相关方**：对所述内容有直接商业或政治利益的来源（如公司宣称自家产品的效果）。可以引用，但必须标注立场。其效果声明在无独立验证时，不得作为关键论断的唯一支撑。
- **硬事实**：可独立验证的客观陈述（产品规格、公开定价、财报数字、政策原文等）。硬事实以一手源为准。
- **软声明**：涉及效果、因果、程度判断的陈述（"提升 3x""市场领先"等）。来自利益相关方的软声明须有独立验证才能支撑结论。
- **孤立数字**：缺少对比基准（同比/环比/占比/可比对象）的定量陈述。
- **推理跳跃**：前提到结论之间缺少可验证的中间步骤，读者无法独立复现推理过程。
- **伪装事实**：形式上写成客观陈述，实质是判断或推测，且未标明性质。

---

## 红线（一票否决）

触发任一条，总分封顶 17 分（不及格），并在评估报告中标明触发项：

1. **编造数据**：引用不存在的来源，或捏造无法追溯的数字。
2. **伪装事实支撑核心结论**：核心判断的关键支撑中，观点被写成事实且未标注。
3. **单一利益相关方定论**：核心结论仅依赖一个利益相关方的软声明，无任何独立验证或对冲。
4. **结论无法回溯到证据**：核心判断找不到对应的事实或数据支撑，纯粹是断言。
5. **回避已知反面证据**：报告可及范围内存在公开的强反面证据，但未提及也未回应。

---

## D1 — 事实准确性

评估报告中的事实陈述是否可靠、可追溯。

| 子指标 | 说明 |
|--------|------|
| 交叉验证 | 关键数据点是否有 ≥2 个独立来源；来源间差异是否显式列出 |
| 来源质量 | 硬事实是否引用一手源；利益相关方的软声明是否标注了立场 |
| 可追溯性 | 每个数据点是否标注来源名称和时间；无法验证处是否标注 `[待补充]` |
| 时效性 | 数据是否足够新；过时数据是否注明时间并说明是否仍适用 |

## D2 — 逻辑严密性

评估从证据到结论的推理链是否经得起追问。

| 子指标 | 说明 |
|--------|------|
| 推理链完整 | 每个核心结论是否有可追溯的"前提 → 推理 → 结论"链条，无跳跃 |
| 推理步幅合理 | 每一步推进是否足够小，读者可独立验证；大跨度推理是否补充了中间论证 |
| 常见谬误 | 是否存在因果倒置、以偏概全、循环论证、幸存者偏差 |
| 隐含假设 | 推理依赖的前提是否被显式列出；假设改变时结论是否仍成立 |

## D3 — 事实与观点分离

评估报告是否让读者清楚区分什么是已知事实、什么是作者判断。

| 子指标 | 说明 |
|--------|------|
| 标注清晰度 | 事实（Fact）、推断（Inference）、观点（Opinion）是否可被读者明确区分 |
| 推断有据 | 每个推断是否标明了所依赖的事实和假设 |
| 观点标主体 | 主观判断是否说明是谁的判断（作者 / 引用对象 / 市场共识） |
| 无伪装事实 | 是否存在将观点写成客观陈述的情况 |

## D4 — 结构完整性

评估报告作为一个整体是否自洽、完整、比例得当。

| 子指标 | 说明 |
|--------|------|
| 基本骨架 | 是否具备"背景/现状 → 分析 → 结论/建议"的最低结构 |
| 首尾呼应 | 结论是否回应了开头提出的问题；偏离是否有说明 |
| 比例得当 | 各部分篇幅是否与其对结论的重要性匹配 |
| 无悬置线索 | 正文提出但未回答的问题是否在后文闭合或显式标注为开放问题 |

## D5 — So What 检验

评估报告是否从分析落到了可指导决策的产出。

| 子指标 | 说明 |
|--------|------|
| 建议可执行 | 建议是否具体到读者知道下一步做什么，而非"建议持续关注" |
| 颗粒度区分 | 不同建议之间是否区分了优先级、时间框架和前提条件 |
| 建议有据 | 每条建议是否能回溯到正文中的分析和证据 |
| 范围声明 | 如果报告定位为纯信息梳理，是否在开头声明了不含决策建议 |

## D6 — 时效性与边界感

评估报告是否诚实交代了自身的有效范围。

| 子指标 | 说明 |
|--------|------|
| 时间窗口 | 是否声明数据截止时间和分析的预期有效期 |
| 适用边界 | 是否说明结论在什么条件/地域/行业/规模下成立 |
| 失效条件 | 是否指出哪些外部变化（政策、技术、竞争格局）会使结论失效 |
| 不确定性披露 | 证据不足或判断低确信时，是否主动标注而非写成确定性结论 |

## D7 — 量级感

评估报告中的数字是否帮助读者建立直觉，而非制造信息幻觉。

| 子指标 | 说明 |
|--------|------|
| 有锚定 | 关键数字是否给出对比基准（同比、环比、占比、可比对象） |
| 有基线 | 变化类数据（提升 X%、缩短 Y 倍）是否说明基线是什么 |
| 口径一致 | 是否区分存量/增量、名义值/实际值、年化/实际等易混淆口径 |
| 无孤立数字 | 删去上下文后仍能被读者正确理解的数字占比 |

---

## 评分标准

每个子指标按以下标准给分，维度得分 = 4 个子指标得分的均值（保留一位小数），再四舍五入到 0.5 档：

| 表现 | 分值 |
|------|------|
| 全面达标，无明显问题 | 5 |
| 基本达标，有少量瑕疵 | 4 |
| 部分达标，有明显但不致命的问题 | 3 |
| 问题较多，影响报告可信度或可用性 | 2 |
| 严重不足 | 1 |
| 完全缺失或完全不可接受 | 0 |

## 总分解释

| 总分 | 判定 |
|------|------|
| 30-35 | 可直接用于决策场景 |
| 24-29 | 强初稿，需少量修订 |
| 17-23 | 存在明显短板，需重点返工 |
| < 17 | 不具备使用条件，或已触发红线 |
