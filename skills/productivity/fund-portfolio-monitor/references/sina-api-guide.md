# Sina Finance API 速查手册

> 最稳定的中文金融市场实时数据源。返回 GBK 编码，中文乱码但数值字段完全可读。

## 基金净值

```
URL:  https://hq.sinajs.cn/list=f_{code}
示例: curl -s "https://hq.sinajs.cn/list=f_000217" -H "Referer: https://finance.sina.com.cn"
返回: var hq_str_f_000217="名称,最新净值,昨收,累计净值,日期(YYYY-MM-DD),...";
```

- 多只合并: `f_000217,f_012734,f_016708` (逗号分隔，上限约20只)
- 返回的是昨日已确认净值，不含盘中估值
- 不含涨跌幅，需自行计算: `(最新净值-昨收)/昨收 × 100%`

## 每日涨跌计算

Sina 指数字段含义分两种端点，切勿混淆（2026-08-20 已用 eastmoney 交叉验证）：

**s_ 宽基指数端点**（`s_sh000001` 等，可靠，直接给涨跌幅）:
```
字段0: 名称
字段1: 当前价
字段2: 涨跌额
字段3: 涨跌幅%   ← 直接用这个
字段4+: 成交量,成交额
```

**sh/sz 板块指数端点**（`sh000819`、`sh000685`、`sz399811` 等）——实际字段顺序与旧文档相反，**字段1 是开盘价不是当前价**:
```
字段0: 名称
字段1: 开盘价      ← 不是当前价！曾误当成"当前价"导致涨跌幅算错
字段2: 昨收价
字段3: 收盘价(最新)  ← 真正的当日收盘价，用它算涨跌幅
字段4: 最高价
字段5: 最低价
```
计算涨跌幅用 `(字段3收盘 − 字段2昨收) / 字段2昨收 × 100%`。

验证样本（2026-08-20 有色 sh000819）: Sina=`9222.50,8990.40,9090.37,9367.94,9028.46`；eastmoney=`今开9222.50 昨收8990.40 最新9090.37 最高9367.94 最低9028.46 涨跌+1.11%`。字段一一对应，完全吻合。

```bash
# 计算涨跌幅
python3 -c "print(round((当前价-昨收价)/昨收价*100, 2))"
```

## 注意事项

1. **GBK 编码**: 中文名称全部乱码，用代码识别即可
2. **Referer 头必需**: 不加 Referer 可能被拒绝
3. **批量查询**: 逗号合并多个代码，减少请求次数
4. **盘中实时**: 交易时段数据实时更新（约15秒延迟）
5. **无历史**: 只返回最新快照，不提供历史序列
