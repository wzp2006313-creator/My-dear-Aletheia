# 基金快报模板

## 数据源

- **基金净值/估算**: `https://fundgz.1234567.com.cn/js/{code}.js`
- **市场指数**: `https://push2.eastmoney.com/api/qt/ulist.np/get` (上证/恒生/恒生科技/板块ETF)
- **历史净值**: `https://api.fund.eastmoney.com/f10/lsjz?fundCode={code}` (5日趋势)
- **基金代码查询**: `https://fundsuggest.eastmoney.com/FundSearch/api/FundSearchAPI.ashx` (代码验证)

优先使用直接 API，web_search/web_extract 在 fundf10/danjuanfunds 上通常被屏蔽。

## 报告结构

```
⚠️ 数据说明 + 免责声明
---
🔴 亏损关注（3只基金表格 + 逐一深度分析 + 近5日净值走势）
---
🟢 盈利持仓（今日涨跌TOP3 + 全部估值一览表 + 当日核心信号）
---
💡 今日策略（4-5板块：有色金银/恒生科技/科技止盈/黄金/其他QDII）
---
📊 组合健康度总评（指标表格 — **可选**，当MCP/news数据源可用时必含，仅API数据时可省略）
---
⚠️ 免责声明（固定结尾）
```

> **注意**: 当运行在 cron 模式或 MCP 服务器不可用时，可简化报告。核心必须保留：🔴亏损关注 + 🟢盈利持仓 + 💡策略建议 + ⚠️免责声明。组合健康度总评和板块深度分析可适度缩减。

## 板块策略框架（每期必含）

### 🥇 有色金属/金银珠宝
- 判断: 观望/企稳/反弹中
- 建议: 不加仓/可定投/减仓
- 关键观察点: 金价$4,200关口、沪金期货、有色指数

### 🥈 恒生科技
- 判断: 承压/反弹/震荡
- 建议: 持有/减仓/加仓
- 关键观察点: 恒生科技指数点位、南向资金

### 🥉 科技止盈（AI/半导体/芯片/消费电子）
- 盈利厚度判断
- 止盈建议（设置回撤线/分批减持）
- 分基金差异化建议

### 🏅 黄金ETF
- 压舱石角色确认
- 是否加仓判断

### 🌐 纳斯达克/消费等
- 简要判断

## 关键计算公式

```
回本需涨 = abs(亏损金额) / 当前市值 × 100%
亏损率 = 亏损金额 / (当前市值 + abs(亏损金额)) × 100%
```

## 报告语气

- 数据驱动，理性克制
- "建议"而非"指令"
- 每段策略必须有"判断→建议→观察点"三段式
- 免责声明结尾固定格式
