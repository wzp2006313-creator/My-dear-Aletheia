**Madhu Guru（Meta，Sr Director AI）**

#### 🎙️ 播客

**The MAD Podcast with Matt Turck —「When AI Improves Itself | Richard Socher (Recursive)」**
嘉宾 Richard Socher（前 Salesforce 首席科学家，Recursive 创始人兼 CEO，刚以 6.5 亿美元融资做「AI 造 AI」）携新书《The Eureka Machine》对话 Matt Turck。核心要点：
- **科学进步在放缓**：抗生素解决了细菌感染，但病毒、癌症远未像细菌那样被「解决」；广义相对论级的基础理论进展也停滞——直觉上研究者与资金都更多了，但真正的突破在变慢。
- **递归自我改进（RSI）**：核心主张是「凡是能被模拟的，AI 都能解决」，从而进入「AI 改进 AI」的自我加速循环，这是 Recursive 公司押注的「重大解锁」。
- **模拟 + 验证器 = 超人类 AI**：任何可模拟、可验证的领域，AI 都能在模拟中无限次实验，最终在该领域超过人类（围棋、国际象棋等完全信息游戏是例证）。
- **幻觉可以是特性而非缺陷**：在 AI 驱动的科学中，幻觉可用于探索新型蛋白质——「AI 能记忆，也能生成新东西」。
- **《Eureka Machine》的四大支柱**：① 用 LLM 摄取世界知识（他特别谈到 Anthropic/OpenAI 闭源、中国开源蒸馏再开源回互联网的循环）；② 模拟；③ 验证器；④（结合）虚拟细胞——让 AI 在虚拟细胞里做扰动实验，最终走向自驱动实验室与 agent swarm，算力是当前主要瓶颈。

### 💡 我的分析
> 标注：以下为基于上述事实的归纳与推论，非 feed 原文。

**最让我意外的，是「需求过载」已经成为一个高频、可验证的信号。** Astra 暂停 Pro 新订阅、Steinberger 喊「Astra 需求涨太快」、Vercel 日部署 1000 万次且为 agentic 部署压力提速 p99 91%——三条独立信息指向同一件事：AI 的算力/推理/部署需求正在从「供给驱动」切换到「需求过载」，服务商开始主动限流。这是产业周期里少见的拐点特征。

**趋势加速 vs 降温（我的判断）：**
- 加速——(1) **企业 agent 化**：Box × OpenAI 把企业内容接入 ChatGPT、Levie 强调 agent 真正 ROI 在「流程再造」，企业从「试验」走向「部署」；(2) **科学 AI / RSI**：Socher 的 Recursive 融资 6.5 亿美元 + 新书，把「AI 造 AI 做科研」从概念推到资本与产品层面；(3) **agentic 基础设施**：Vercel「每个 agent 一台电脑」、Rauch 的部署量数据，说明 agent 已成为基础设施层的真实负载。
- 降温——**「灭绝风险」叙事在 builder 圈遇冷**：Replit CEO Amjad Masad 明确说灭绝风险「绝非其一」，对比此前 RSI/接管论的焦虑，头部 builder 对「100% 灭绝」这类极端叙事的态度明显冷静、务实（更担心的是网络安全这类具体风险）。

**给创业者和开发者的 actionable 启发：**
1. **把 eval 从「看结果」升级为「看步骤」**：Madhu Guru 的第 10 篇 eval 指南（衡量步骤而非结果）值得照做——两个 agent 答案相同但过程质量天差地别，过程可观测性（工具调用次数、检索效率、错误恢复）才是衡量 agent 质量的关键指标，也是差异化所在。
2. **做 agent 基础设施正处顺风**：供给端紧张（Astra 限流、部署量暴增），推理基建、成本优化、token 效率、以及「每个 agent 一台电脑」的算力编排工具，短期仍有明确需求。
3. **警惕算力/订阅的「供给天花板」**：如果你重度依赖某个模型的订阅或 API，Astra 暂停 Pro 订阅是警钟——把关键工作流做成多模型可切换、把单位经济按「真实算力成本」而非补贴价建模，避免被单一供应商的容量瓶颈卡住。
4. **企业内容/数据是 agent 的护城河**：Box × OpenAI 合作印证 Levie 反复强调的点——模型人人可用，真正不可替代的是你的机构知识、数据资产与领域工作流。现在就开始系统化数字化这些资产。
