#### 🎙️ 播客：Training Data — Amin Vahdat（Google AI 基础设施负责人）

主题：《The Physics & Economics of Frontier AI》（发布于 2026-10-06）。🔗 https://www.youtube.com/playlist?list=PLOhHNjZItNnMm5tdW61JpnyxeYH5NDDx8

核心要点：
- **硬件专用化 vs 灵活性的权衡**：越专用化某工作负载，硬件越快越省电但也越不灵活；关键在于判断目标负载是否"持久"——若只火两三个月，窗口太窄不值得做专用硬件。
- **史无前例的扩张规模**：本轮的算力建设"在人类历史上都前所未见"，数据中心是"人类能力的纪念碑"。
- **10 万张芯片的可靠性**：芯片是 2/4/8+ chiplet 组成的封装，10 万块必然有故障，需要近实时检测与恢复。
- **2 倍/年以上的硬件性能提升是可能的**，且这是"免费乘数"，能抬升其上的每一层（软件、模型、应用）。
- **Transformer = 线性代数原语**：向量/矩阵乘 + softmax，这些原语已基本固化进硬件。
- **与 DeepMind 深度协同**：共同最大化"每瓦特的交付智能/吞吐"（goodput per watt），并在芯片 tape-out 前就介入设计。
- **长时程 Agent 是今年最大的工作负载变化**。
- **电力是唯一根本约束**：其他问题都"知道怎么解决，只是时间问题"，唯独电力是长期绑定的硬约束；核电/充足清洁能源可能破解。
- **训练集群正向 1GW 逼近**；开放标准（类比 IP 协议的"窄腰"）是互联互通的关键。
- **2036 年的计算机**：10 年尺度上集成度会极大提升，但不确定性"锥"极宽。

### 💡 我的分析

> 说明：以下为基于今日事实的分析与推论，非 feed 原始内容。

**今天最让我意外的是什么？**
是 Anthropic 主动"踩刹车"。在同一天既宣布 Claude Docs/Slides/Design 全面免费开放（扩张信号），又宣布暂停 Claude Startups 的额度优惠（收缩信号）——数十万申请把供给端打爆了。这其实是一个强烈的行业信号：**AI 创业生态的需求增长速度，已经超过了头部模型厂商愿意补贴的供给能力**。免费额度从来是获客工具，暂停意味着 Anthropic 认为"靠补贴换来的这批开发者"性价比在下降，或真实算力成本压力已经压到必须设限。

**哪些趋势在加速？哪些在降温？**
- **加速**：个人/消费级 Agent 基建。Madhu Guru（Meta）的"全栈重建"论、Box Mount、Garry Tan 的"Agent 型 IC"、长时程 Agent 成为最大工作负载变化——多个独立信号指向同一个方向：Agent 正从"企业 API 集成"阶段，正式进入"消费产品 + 操作系统级"阶段。
- **降温**：① 纯免费额度/补贴型增长——Claude Startups 的暂停是最直接证据；② 传统 seed→Series A 融资的老路径——Nikunj Kothari 明说旧式指标已不适用，门槛每月变高。

**对创业者/开发者的 actionable 启发：**
1. **别把商业模式建立在模型厂商的补贴上**。Claude Startups 的教训就在眼前——额度随时可能被复审甚至收回，要尽早算清自己的单位经济模型。
2. **去做"Agent 就绪"的中间层**：身份/权限/安全、面向 Agent 的 OS 与云、文件系统挂载（Box Mount 方向）都是今天被点名的空白层，竞争少、需求明确。
3. **把"模型能力追不上你的需求"当作窗口期而非死路**：Nikunj 的"蟑螂"策略值得认真对待——先做到 default profitable 活下来，等模型能力到位后需求会自己爆发。
