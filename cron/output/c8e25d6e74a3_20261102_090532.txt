#### 播客（1 期）

**《Using Agents for Long-Horizon Financial Work — Aman Singh, Arca》**（Latent Space Podcast，AI Engineer NY 大会现场）[🔗](https://www.youtube.com/@LatentSpacePod)

核心要点（事实，源自节目转录）：
- Arca 是一家融资 **6400 万美元**的"AI-native 财富管理公司"，Aman 反复强调一句话：**"我们不是 SaaS 公司，我们就是公司本身"**。这让 Arca 能够标准化"这项工作应该怎么做"，从而让 agent 以标准方式参与。
- 典型工作流是**跨 10 天的长周期任务**（例如客户发来 10 万美元税单 → 分析最优化变现路径 → 再平衡组合 → 执行交易）。**分析全自动，但"动钱"严格留人**：资金移动、资产清算、直接联系客户，全部 human-in-the-loop，有 custodian 的深度 API 集成加确定性护栏。
- **"agent prompt 人多于人 prompt agent"**：agent 靠长期记忆持久化 + 每日"反思/做梦"进程，在恰当节点主动拉入正确的人（第 7 步的执行者不需要在第 1 步就知道）。
- **安全是确定性 + 模型双层**：写库动作有 LLM 级验证；在边界检测 prompt injection；数据出系统（web 搜索、发日历邀请）时用确定性 PII 检查 + 多个小模型共识防数据外泄。
- **auditability by default**：agent 和人类的每一次动作都产生 changelog（谁、在哪个系统、改了什么、何时），既满足合规又反哺 agent 能力。
- **对托管 agent 平台的态度**：对 Anthropic/OpenAI 的模型很乐观，但对"managed agents"这类产品持保留——"**把智能交给别人，你就失去了影响业务的能力**"，所以自己拥有 harness。
- **反馈闭环**：每个员工的编辑/取消都带"为什么"并成为 eval；每晚跑一个 meta-agent 汇总真实世界 trace，建议 harness 改进，但仍有人类工程师在发布 prompt 变更前把关（"agent 会把每个小修复都改成一整段 prompt"）。
- **实战案例**：一个潜在客户本已有一名收费 1500 美元的顾问，Arca 的 agent 读完文件后，发现该顾问还收取了客户不知情的费用、且并非 fiducial（不承担受托义务）。

*以下为分析/推论，非 JSON 事实。*

**今天最让我意外的**
- 不是某条技术新闻，而是 **Levie 的"试金石"被这么直白地写了出来**。它把过去半年散见于各处的体感——"AI 已经不只是快一点"——浓缩成一条可自我检验的标准，且明确指向"质变而非量变"。这比任何单点产品发布都更能标记行业心态的迁移。（分析，源于 Levie 推文）

**哪些趋势在加速 / 降温**
- **加速**：agent 进入**受监管、长周期、高利害**的真实业务。Arca 的 10 天税务/交易流程说明 agent 不再是"demo 里跑 30 秒"，而是要在"钱、合规、客户信任"三条高压线下持续运行数天——这要求记忆、审计、护栏、反馈闭环全部工程化。（分析，源于播客）
- **降温**：对"全自动代理一切"的狂热。Arca 明确**不在今天做自主交易**、人类工程师仍要审核 prompt 变更、动钱必须留人——即便在最激进的 agent 公司，人在关键环的"闸门"反而被强化了。（分析，源于播客）

**对创业者 / 开发者的 actionable 启发**
1. **把"护栏 + 审计"做成产品的一等公民**：Arca 的确定性安全层 + changelog 不是附加成本，而是它进入受监管财富管理市场的入场券。如果你的 agent 产品没有"谁、何时、改了什么"的完整留痕，就进不了 regulated 行业。（分析，源于播客）
2. **"拥有 harness = 拥有业务"**：Arca 拒绝托管 agent 平台的逻辑可迁移到任何公司——你自建基础设施层的控制力，决定了你对模型准确度、知识库、反馈闭环的掌控上限。（分析，源于播客）
3. **用"试金石"审查自己的 AI 项目**：拿 Levie 的问题问一遍——"这个产出，AI 之前我能不能做出来？"如果答案是"能，只是慢一点"，说明你还在旧范式里，值得重新设计工作流。（分析，源于 Levie 推文）
4. **别在 effort level 上浪费争论**：Swyx 和 Karpathy 的案例说明，effort 档位本质是"按需调参"，真正的杠杆在 **critique loop / 反馈循环**，而不是无限堆火力。（分析，源于 Swyx 推文）
